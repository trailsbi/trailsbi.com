Microsoft sample · VanArsdel Ltd

Competitive Marketing Analysis

A CMO's view of a fictitious manufacturer: market share, product volume, sales and sentiment against competitors.

Open the live page About the sample Download from Microsoft
trailsbi "D:\Reports\Competitive Marketing Analysis"

TrailsBI Analysis

  • Error

    A visual on Top 10 Regions sorts by Sales[Total Category Volume], which doesn't exist in the model. Power BI drops the sort silently; TrailsBI flags it.

  • Lineage

    All 23 measures live in a Calculations table with one placeholder column. TrailsBI counts them as that table's own, so the table is never suggested for deletion.

  • Impact

    Revenue is a one-line SUM, yet 10 measures and 12 items in total depend on it.

Human Resources

New hires, active employees and separations, to spot trends in hiring strategy and potential bias.

Open the live page About the sample Download from Microsoft
trailsbi "D:\Reports\Human Resources Sample"

TrailsBI Analysis

  • Error

    7 measures reference columns without their table, for example ROUND(AVERAGE([Age]), 0).

  • Error

    Year, Qtr, Day, MonthNumber and PeriodNumber are set to sum by default, so a visual can add up years.

  • Reports

    The Info page has text and images but no data visuals. The Reports view shows that at a glance.

Microsoft sample · Contoso

Regional Sales

A sales manager's view of which products and regions drive revenue, built on Dynamics 365 Sales data.

Open the live page About the sample Download from Microsoft
trailsbi "D:\Reports\Regional Sales Sample"

In Microsoft's file the Excel source sits in a personal OneDrive folder. For this demo only that address was changed, to contoso.sharepoint.com.

TrailsBI Analysis

  • Error

    A Key Influencers visual explains by Accounts[Industry], [Territory] and [Region]. None of those columns exist.

  • Error

    A page filter uses Opportunities[Opportunity Owner Name], which is also missing from the model.

  • Impact

    Revenue Won feeds 36 items: measures, visuals across 11 pages and the filters that use it.
