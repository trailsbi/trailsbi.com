Common Installation issues

  1. Warning: The script trailsbi.exe is installed in '...\Scripts' which is not on PATH.

    On Windows, Python from the Microsoft Store or the Python install manager puts commands installed with pip in a Scripts folder that is not on your PATH. pip warns about it while installing, and running trailsbi "pbip-project-path" returns 'trailsbi' is not recognized.

    Solution

    • Open the Start menu
    • Search for Edit environment variables for your account
    • Select Path and click Edit
    • Click New and paste the folder from pip's warning (it ends in \Scripts)
    • Click OK then again OK

    Windows that were already open keep the old PATH. In a NEW PowerShell or Command Prompt window:

    trailsbi "your-PBIP-project-folder-or-file-path"

Installed with uv? Run uv tool update-shell once, which adds uv's tool folder to your PATH, then open a new terminal.

Still not recognized? Check which Python pip used with python -m pip --version, and that pip install trailsbi ran with that same Python.
